# Student Performance Analyser

## Project Overview
Student Performance Analyser is a Java console-based application designed to analyse student academic performance. It collects student marks, calculates averages and categorises students according to their academic results.

## Features
- Accepts the number of students.
- Collects student marks.
- Calculates individual student averages.
- Identifies passed and failed students.
- Identifies students who achieved distinctions.
- Displays student performance statistics.

## Technologies Used
- Java
- Java Scanner
- Conditional Statements
- Loops
- Variables and Data Types

## Learning Objectives
This project demonstrates practical understanding of Java fundamentals, including user input, arithmetic operations, loops, conditional logic and basic data analysis.

## How to Run
1. Clone this repository.
2. Open the project in VS Code or another Java IDE.
3. Compile the Java file.
4. Run the Main class.
